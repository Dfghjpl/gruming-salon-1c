# gruming-salon-1c
Автоматизация груминг-салона на 1С:Предприятие 8.3

## Описание проекта
Конфигурация для автоматизации работы груминг-салона. Реализована с нуля на платформе 1С:Предприятие 8.3.

## Функциональность
- Учет клиентов и животных
- Запись на услуги
- Учет оказанных услуг и расчета стоимости
- Складской учет товаров (шампуни, кондиционеры и т.д.)
- Отчетность по выручке и загрузке мастеров

## Реализованные объекты метаданных

### Справочники
- Клиенты
- Животные
- Услуги
- Мастера
- Номенклатура

### Документы
- Приём животного
- Оказание услуги
- Продажа товаров
- Возврат

### Регистры накопления
- Услуги 
- Товары на складе

### Отчеты 
- Журнал записей
- Выручка за период
- Загрузка мастеров


## Технологии
- 1С:Предприятие 8.3
- Встроенный язык 1С
- СКД (Система компоновки данных)
- Запросы 1С
